# 12-Month AI Operator Plan

## North Star

Become a systems builder who designs, deploys, and operates AI workflows for real business outcomes.

## Month-by-Month

### Month 1: LLM Foundations
- Learn: tokens, context windows, embeddings, model limits
- Build: prompt notebook + baseline script
- Ship: `scripts/llm_playground.py` and first test results

### Month 2: Prompt Control + Structured Outputs
- Learn: system prompts, few-shot examples, JSON schema constraints
- Build: prompt test harness with pass/fail checks
- Ship: reliability report for 30 test cases

### Month 3: Python Workflow Automation
- Learn: API requests, data parsing, file I/O, modular scripts
- Build: CSV to AI analysis pipeline
- Ship: one automation script with reproducible output

### Month 4: Integration Layer
- Learn: REST, OAuth/API auth, webhook patterns
- Build: Salesforce/Gong/Outreach data pull to Slack summary
- Ship: integration pipeline with retries and errors logged

### Month 5: Automation Orchestration
- Learn: n8n/Zapier/Make patterns and tradeoffs
- Build: transcript to summary to action-items flow
- Ship: visual workflow + coded fallback

### Month 6: RAG Systems
- Learn: chunking, embeddings, retrieval quality, citations
- Build: RevOps knowledge assistant grounded on source docs
- Ship: RAG v1 with citation-only answers

### Month 7: Agentic Workflows
- Learn: tool-calling, planning loops, failure handling
- Build: account-health analysis worker using multiple tools
- Ship: agent with guardrails and deterministic output contract

### Month 8: Data Pipelines
- Learn: ETL, batch vs real-time, idempotency, queues
- Build: ingestion + storage + analysis job chain
- Ship: event-driven pipeline with retry strategy

### Month 9: Cloud Deployment
- Learn: serverless architecture, secrets, IAM basics
- Build: AI microservice deployed on AWS
- Ship: running endpoint + deployment docs

### Month 10: Product Layer
- Learn: AI UX, feedback loops, quality telemetry
- Build: RevOps assistant UI and API backend
- Ship: usable internal alpha with user feedback

### Month 11: Architecture + Scale
- Learn: multi-model patterns, evaluation loops, system decomposition
- Build: architecture docs for your capstone
- Ship: architecture decision record set

### Month 12: Capstone
- Build: AI RevOps Copilot (or CS Account Management Engine)
- Ship: production-style capstone with docs, demos, and metrics

## Definition of Done (per month)

- One repo artifact or major module
- One architecture/decision document
- One metrics snapshot (quality, latency, cost)
- One short demo video
