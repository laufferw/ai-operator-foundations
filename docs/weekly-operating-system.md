# Weekly Operating System

## Time Budget (5-7h)

- Learning: 2h
- Building: 3h
- Evaluation: 1h
- Documentation: 1h

## Weekly Workflow

1. Plan: choose one deliverable and one metric improvement target
2. Build: implement minimum viable slice
3. Evaluate: run tests and score output quality
4. Publish: write weekly note and commit artifacts

## Weekly Metrics

- Output schema validity rate
- Task success rate
- Average latency (ms)
- Cost per successful run
- Failure/retry count

## Personal Rule

No week ends without a commit and a written summary.
