# AI Operator Foundations

A structured 12-month program to become an AI Operator / AI Systems Builder focused on RevOps systems.

## Objectives

- Build production-minded AI systems, not just demos.
- Develop strengths across AI, engineering, systems, and product.
- Ship portfolio artifacts monthly.

## Repository Structure

- `docs/` learning roadmap, operating system, and project specs
- `scripts/` executable learning/build scripts
- `evals/` test cases and evaluation outputs
- `apps/` project implementations by phase

## Start Here

1. Read [docs/12-month-ai-operator-plan.md](docs/12-month-ai-operator-plan.md)
2. Follow [docs/90-day-sprint.md](docs/90-day-sprint.md)
3. Execute Week 1 in [docs/week1.md](docs/week1.md)
4. Run the first script in `scripts/llm_playground.py`

## Weekly Cadence (5-7 hours)

- 2h learning
- 3h building
- 1h evaluation and refactor
- 1h writing and publishing progress

## Core Stack

- Python, TypeScript, FastAPI
- OpenAI API, Anthropic API
- Postgres/Supabase
- AWS Lambda, API Gateway, EventBridge
- Salesforce API, Slack API
